Los contenidos y demostraciones deberán ser verificables. Las fuentes se citarán en formato IEEE y se declarará el uso de herramientas de inteligencia artificial cuando corresponda.

No se publicarán datos personales de participantes ni evidencias privadas en este repositorio.
